Are μ₁, μ₂, μ₃, … all equal?

New question, new statistic: F.

Why not just run many t tests?

With k groups you would need a t test for every pair. Each test has its own chance α of a false alarm, and those chances pile up.

P(at least one false alarm) = 1 − (1 − α)m m = k(k − 1) / 2 pairwise tests

False-alarm lab

Pairs m–
Each test–
Overall risk–

All pairwise t tests
One ANOVA F test

Every simulated group comes from the same population (5 runs per group), so any “significant” result is a false alarm. The formula assumes independent tests. Real pairwise tests share data, so their rate is a little lower, but still far above α.

The fix: ANOVA tests all means in one go, keeping the overall error rate at α.

Part 1

The idea of ANOVA

Comparing means by comparing variances

Hypotheses in ANOVA

H₀ — Null hypothesis

H₀: μ₁ = μ₂ = μ₃ = … = μk

All population means are equal.

H₁ — Alternative hypothesis

H₁: at least one μi differs

Not all population means are equal.

✓ Correct reading of H₁

At least one group mean is different from the others.

✗ Wrong reading of H₁

All group means are different from each other.

ANOVA tells you whether there is a difference — not where it is.

Two sources of variation

Between groups

How far the group means are from the grand mean.

Contains: treatment effect + noise

Within groups

How spread out the values are inside each group.

Contains: noise only

If H₀ is true, both estimate the same noise → ratio ≈ 1

The F ratio

F = MS betweenMS within signal ÷ noise

Signal: MS between

Variance of the group means (scaled by n)

Noise: MS within

Pooled variance inside the groups

F

How many times bigger the signal is than the noise

Reading the F value

F ≈ 1

Group means differ about as much as noise predicts.

No evidence against H₀

F ≫ 1

Group means differ much more than noise predicts.

Evidence against H₀

F < 0 ?

Impossible — both parts are variances.

F ≥ 0 always

Large F → reject H₀. How large is “large”? The F distribution decides.

SSB

Variation explained by the groups

SSW

Leftover variation (noise)

The formulas

Between groups

SSB = Σ ni (x̄i − x̿)²

df = k − 1

MSB = SSB / (k − 1)

Within groups

SSW = Σ Σ (xij − x̄i)²

df = N − k

MSW = SSW / (N − k)

F = MSBMSW

Shortcut: SSW = Σ (ni − 1) si²

    Part 3

    After the F test

    Post hoc comparisons, effect size, and assumptions

    Post hoc tests: which groups differ?

    Tukey HSD

    All pairwise comparisons

    Most common default

    Bonferroni

    Use α / m for each of m tests

    Simple, conservative

    Scheffé

    Any comparison, even combinations

    Most conservative

    Only run post hoc tests after a significant F.

    Tukey HSD for the caching example

    HSD = q · √( MSW / n )

    Two means are declared different when the gap between them is larger than HSD (the dashed line). q is the studentized-range critical value for k = 3 groups and 12 error df.

    Effect size: how much do groups matter?

    η² = SSBSST = 253.33391.33 = 0.65
    65% explained by caching strategy
    35% noise

    65% of the variation in response time is explained by the caching strategy.

    Rough guide

    η² ≈ 0.01small
    η² ≈ 0.06medium
    η² ≥ 0.14large

    A significant F says an effect exists. η² says how big it is.

    Assumptions of ANOVA

    Independence

    Random samples; groups do not influence each other

    Normality

    Each group ≈ normal — check dot plots or histograms

    Equal variances

    Rule of thumb: largest s / smallest s < 2

    Our example: sA = 3.81, sB = sC = 3.16 → ratio 1.20 < 2 ✓   Formal check: Levene's test for equal variances.

    When assumptions fail

    Unequal variances→Welch's ANOVA
    Strong skew or outliers→Log transform or Kruskal–Wallis (Module 14)
    Same subjects measured repeatedly→Repeated-measures ANOVA

    ANOVA is fairly robust to mild non-normality when group sizes are equal.

    ANOVA compares means by asking: is the between-group signal bigger than the within-group noise?

    Significant F → find which groups differ → report how much it matters.

    Exit ticket

    Because it decides about the means by comparing two variances. MS between measures how much the group means vary around the grand mean, and MS within measures how much the values vary inside the groups. If all population means are equal, both estimate the same noise and F ≈ 1. If the means really differ, the between-group variance is inflated and F becomes large.
